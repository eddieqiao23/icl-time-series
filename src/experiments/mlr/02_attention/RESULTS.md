# Attention results

## Design

The canonical noisy `T=3, K=2` checkpoint and an architecture-matched
untrained model were evaluated on 10 independent coefficient pools and 128
prompts per pool. For prediction-bearing input tokens at positions
`5, 10, 20, 30, 40, 49`, attention to earlier tasks was separated by whether
the earlier task used the same or a different component. Each group was
normalized by its available key count before computing selectivity
`(same - different) / (same + different)`.

## Result

| Layer | Trained selectivity | Untrained selectivity |
|---:|---:|---:|
| 0 | 0.007 | 0.000 |
| 1 | 0.061 | 0.000 |
| 2 | -0.018 | 0.000 |
| 3 | 0.111 | 0.000 |
| 4 | 0.166 | 0.000 |
| 5 | 0.496 | 0.000 |

Uncertainty bars in `selectivity_by_layer.png` are standard errors across
coefficient pools. The final layer strongly favors prior tasks generated by
the active component, while the same architecture before training has no
measurable component preference. Selectivity is not monotonic: layer 2 has a
small negative mean before the strong late-layer increase.

This establishes component-selective routing, not causal necessity. Experiment
04 tests whether the selected context and heads affect prediction error.
