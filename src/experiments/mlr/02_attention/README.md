# 02 - Attention and component selectivity

## Question

Where does attention flow across tasks, and does the query task preferentially
attend to tasks generated by the same regression component?

## Initial analyses

- attention by layer and task index;
- input-token versus output-token attention;
- per-head attention profiles;
- same-component versus different-component selectivity;
- selectivity under controlled coefficient cosine similarity;
- randomly initialized model control.

Attention is evidence about information routing, not proof that attended
tokens causally determine the prediction. Causal claims belong in experiment
04.

## Implementation

`evaluate.py` measures attention from prediction-bearing input tokens to all
earlier task input/output tokens. It normalizes same- and different-component
attention by the number of available keys, retains layer/head/position detail,
uses coefficient pools as the uncertainty unit, and repeats the identical
analysis with an architecture-matched untrained model. `plot.py` produces
layer, head, and coefficient-similarity summaries.
